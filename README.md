# Run Club platforma

Mikroservisni sustav koji povezuje run klubove i trkače. Klubovi objavljuju evente s rutom
(sustav računa duljinu i uspon preko OpenRouteServicea), trkači se prijavljuju, a GenAI
preporučuje klubove prema profilu trkača.

Projektni zadatak kolegija *Razvoj skalabilnog produkcijskog IKT sustava* (PMF / Infobip).
